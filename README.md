# Codex Timeline

Codex Timeline is a local-first desktop tool for inspecting Codex agent runs (the full execution process of a Codex task).

It aims to turn a Codex session into a clear execution timeline, so you can see what happened during a task: commands, tool calls, file changes, approvals, timing, token usage, retries, and failures.

The project starts with Codex support first. The timeline model is intended to stay adapter-friendly, so other coding agents such as Claude Code or Gemini CLI can be supported later.
